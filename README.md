# @tapsleek/card-engine

Core layout compiler, renderer, and validator for Tapsleek cards and templates.

## Installation

```bash
npm install @tapsleek/card-engine
# or
pnpm add @tapsleek/card-engine
```

## Features

- **AST & Definition Validation:** Strict Zod-backed validation for card template JSON schema.
- **CSS Compiler:** Compiles declarative layout style trees to scoped CSS.
- **Card & Node Renderer:** High-performance React renderer for cards and custom blocks.
- **Built-in Widgets:** Rich catalog of widgets (Lead Form, Social Icons, Testimonials, Business Hours, Maps, etc.).
